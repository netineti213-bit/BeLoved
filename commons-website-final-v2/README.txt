Commons Collective - Deployment Instructions

1. Upload all files to GitHub Pages or Netlify.
2. Ensure the folder structure is intact (assets/css, assets/js, assets/icons).
3. GitHub Pages: Enable Pages -> main branch -> wait for live link.
4. Netlify: Drag & drop the unzipped folder -> live instantly.
5. Test index.html -> mockup.html -> charter.html
6. PDF guide is in assets/ and linked from Welcome page.
